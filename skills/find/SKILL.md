# Find it in Notii

1. **Search** with the key words of the question. If little comes back, search again with other words or a shorter query; `search` also finds notes about the same thing by meaning.
2. **Read** the one to five most relevant notes with `fetch`, chosen by their titles and snippets. Don't fetch everything.
3. **Answer from the notes.** Quote briefly where the exact wording matters and cite each note as `[Title](url)`. Mention when a note was last updated if timing matters.
4. **Be straight about gaps.** If notes disagree, say which is newer. If nothing relevant is there, say so and offer to start a note. Label anything that comes from general knowledge rather than the user's notes.
